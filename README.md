
# FoodHub — Enhanced Starter

This enhanced starter contains:
- React (Vite + Tailwind) frontend (client/)
- Express + MongoDB backend (server/)
- Local multi-image uploads (Multer)
- Monnify payment placeholders and sample init endpoint
- Husky + Commitizen (git-cz) + Commitlint config
- GitHub Actions CI workflow
- Postman collection for API testing

Follow instructions in server/README.md and client/README.md to run locally.

# 🍽️ FoodHub – Food Ordering & Reservation Platform

[![CI](https://github.com/<your-username>/FoodHub/actions/workflows/ci.yml/badge.svg)](https://github.com/<your-username>/FoodHub/actions)

FoodHub is a full-stack web app for ordering food, making reservations, and managing deliveries — built with **React (Vite + Tailwind)**, **Node.js + Express**, and **MongoDB**.

---

## 🚀 Features
- 🧑‍🍳 Food listing with **multiple image uploads (local)**
- 💳 Integrated **Monnify payment** gateway
- 📦 Orders, Reservations & Subscriptions APIs
- 🧰 Husky + Commitizen + Commitlint setup for clean commits
- ⚙️ CI/CD with **GitHub Actions**
